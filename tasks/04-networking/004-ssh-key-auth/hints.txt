Generate a key with ssh-keygen. Use -t ed25519 for the key type, -N "" for an empty passphrase, and -f to set the output path.
Append (don't overwrite) your public key to the authorized_keys file: cat ~/.ssh/id_ed25519.pub >> ~/.ssh/authorized_keys
sshd is strict about permissions — the .ssh directory must not be group/world-writable (700), and authorized_keys must not be readable by others (600).
Full solution:
  ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_ed25519
  cat ~/.ssh/id_ed25519.pub >> ~/.ssh/authorized_keys
  chmod 700 ~/.ssh
  chmod 600 ~/.ssh/authorized_keys
